# DIYRubberDucky
a diy usb rubber ducky (cybersecurity tool)

Concept - a USB Rubber Ducky (original by hak5) built on a ATMega32 chip that acts as a HID input device to rapidly execute scripts when plugged into a computer, for cybersecurity purposes. also has an arasaka logo on the back (cyberpunk 2077) but this is easily removable. 

Features:
- usb-a male port to connect to device
- reset and hwb switches
- 6 pin isp header for programming
